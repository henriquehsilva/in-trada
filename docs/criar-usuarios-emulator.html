Como criar usuários para acesso

Guia para iniciar os emuladores e cadastrar contas locais de administrador, operador ou recepcionista no IN-TRADA.

1

Prepare o ambiente local

O Vite só conecta a aplicação aos emuladores quando a variável abaixo está ativa.

No arquivo .env da raiz do projeto, mantenha a configuração Firebase já existente e acrescente:

VITE_USE_EMULATORS=1
Use somente no desenvolvimento. Sem essa variável, a aplicação pode apontar para o projeto Firebase real. Depois de alterar o .env, reinicie o servidor Vite.

Se ainda não instalou as dependências:

npm install
2

Inicie os emuladores e a aplicação

Use dois terminais abertos na raiz do projeto.

Terminal 1 — Firebase Emulator Suite

npx firebase-tools emulators:start

Terminal 2 — aplicação

npm run dev

Abra a URL exibida pelo Vite — normalmente http://localhost:5173. A interface dos emuladores fica em http://127.0.0.1:4000.

Como confirmar a conexão O console do navegador deve exibir 🔥 Usando Firebase Emulators quando a aplicação carregar.
3

Crie o primeiro usuário pela aplicação

Este é o caminho recomendado, porque cria a credencial no Authentication e o perfil correspondente no Firestore automaticamente.

  1. Acesse http://localhost:5173/cadastro.
  2. Informe o nome completo e um e-mail de teste.
  3. Defina uma senha com pelo menos 6 caracteres.
  4. Escolha a função inicial — normalmente Administrador.
  5. Clique em Criar conta.

Funções aceitas pelo sistema:

OpçãoValor salvoAcesso inicial
Administradoradmin/admin
Operadoroperador/operador
Recepcionistarecepcionista/recepcionista
Resultado esperado A conta aparece na aba Authentication da Emulator UI e um documento com o mesmo UID aparece em Firestore → usuarios.
4

Alternativa: criação manual pela Emulator UI

Use este método para preparar uma conta sem passar pela tela de cadastro. As duas partes abaixo são obrigatórias.

Parte A — criar a credencial

  1. Abra Emulator UI → Authentication.
  2. Clique em Add user.
  3. Preencha e-mail, senha e, se desejar, nome de exibição.
  4. Salve e copie o User UID criado.

Parte B — criar o perfil no Firestore

  1. Na Emulator UI, abra Firestore.
  2. Crie ou abra a coleção usuarios.
  3. Adicione um documento usando exatamente o User UID copiado como Document ID.
  4. Inclua os campos abaixo, respeitando nomes, tipos e letras minúsculas.
CampoTipoExemplo
nomestringAdministrador Local
emailstringadmin@local.test
rolestringadmin
criadoEmstring2026-09-10T12:00:00.000Z
atualizadoEmstring2026-09-10T12:00:00.000Z

Para um recepcionista, inclua também eventoId como string, contendo o ID de um evento existente.

O UID precisa ser idêntico. Criar apenas a conta em Authentication não basta. Se não encontrar usuarios/{uid}, o IN-TRADA encerra a sessão automaticamente.
5

Valide o acesso

Faça uma verificação curta antes de continuar o desenvolvimento.

  1. Se estiver conectado com outra conta, saia do sistema.
  2. Abra http://localhost:5173/login.
  3. Entre com o e-mail e a senha recém-criados.
  4. Confirme que o painel correspondente à função foi aberto.
  • Usuário visível no Authentication Emulator
  • Documento visível em Firestore / usuarios / UID
  • role contém um valor válido
  • Login redireciona para o painel correto
6

Problemas comuns

“Falha no login”

Confira se os emuladores ainda estão executando, se o e-mail e a senha pertencem ao Authentication Emulator e se VITE_USE_EMULATORS=1 estava ativo quando o Vite iniciou.

O login entra e volta imediatamente

O perfil no Firestore está ausente ou usa outro ID. Crie usuarios/{UID da conta} e confirme o campo role.

O usuário abre o painel errado

Corrija role para exatamente admin, operador ou recepcionista. Depois, saia e entre novamente.

Os usuários desapareceram

Por padrão, os dados do Emulator Suite são temporários e podem sumir ao encerrar o processo. Para preservá-los entre execuções:

# Encerrar e exportar os dados
npx firebase-tools emulators:export .firebase-data

# Iniciar importando e salvar alterações ao sair
npx firebase-tools emulators:start \
  --import=.firebase-data \
  --export-on-exit=.firebase-data

Não envie credenciais reais para o emulator e não versione dados exportados que contenham informações sensíveis.
