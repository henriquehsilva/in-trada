1

Pré-requisitos

Confirme essas ferramentas antes de começar. Os comandos abaixo mostram a versão instalada.

# Node.js 18 ou superior
node -v

# npm (vem junto com o Node)
npm -v

# Git
git --version

Se o node -v falhar ou mostrar uma versão abaixo de 18, instale o Node atual em nodejs.org antes de continuar.

2

Clonar o repositório e instalar dependências

git clone <url-do-repositorio> in-trada
cd in-trada
npm install

Isso instala React, Firebase SDK, Tailwind e as demais dependências listadas em package.json.

4

Instalar o Firebase CLI

A CLI é quem sobe os emuladores locais (Firestore, Auth, Storage).

npm install -g firebase-tools
firebase --version

# conecta a CLI com sua conta Google
firebase login

O projeto já vem com um .firebaserc apontando para in-trada, então não é preciso rodar firebase init de novo — as regras (firestore.rules, storage.rules) e a config dos emuladores já estão em firebase.json.

5

Configurar e subir os emuladores

O arquivo firebase.json já define as portas de cada serviço:

Emulator UI · 4000 Firestore · 8080 Auth · 9099 Storage · 9199 Functions · 5001

Com VITE_USE_EMULATORS=1 já setado no passo 3, suba os emuladores em um terminal separado:

firebase emulators:start

Deixe esse terminal aberto. Abra http://127.0.0.1:4000 no navegador — essa é a Emulator UI, onde dá pra ver e editar os dados do Firestore, os usuários do Auth e os arquivos do Storage em tempo real, sem tocar em produção.

Dica Para manter dados entre reinicializações dos emuladores, use firebase emulators:start --export-on-exit=./firebase-data --import=./firebase-data. Isso salva o estado ao encerrar e recarrega no próximo start.
6

Rodar o front-end

Em outro terminal (com os emuladores já rodando), inicie o Vite:

npm run dev

O terminal vai mostrar o endereço local, normalmente http://localhost:5173. Abra essa URL no navegador.

7

Verificar se está tudo local

  • No console do navegador (F12) deve aparecer o log 🔥 Usando Firebase Emulators.
  • Qualquer cadastro, login ou upload feito no app deve aparecer imediatamente na Emulator UI (127.0.0.1:4000), não no console do Firebase de produção.
  • Se o log não aparecer, confira se VITE_USE_EMULATORS=1 está no .env e reinicie o npm run dev — variáveis de ambiente só são lidas na inicialização do Vite.
Erro comum Se o app não conectar aos emuladores, confirme que o firebase emulators:start está rodando antes de abrir o app, e que nenhuma outra aplicação está usando as portas 8080, 9099 ou 9199.
Resumo dos comandos do dia a dia: firebase emulators:start em um terminal, npm run dev em outro.
